# 성경 한 장면 · 시네마틱 대본 작법 가이드 (v2.1)

목표: '이집트 왕자'(1998), '다윗'(2025) 같은 애니메이션 영화처럼 **귀로 보는 영화**를 만든다. 다큐멘터리 내레이션·설교·성경공부 요약이 되면 실패다. 정확성은 지키되, 정확성이 몰입을 죽이는 핑계가 되지 않게 한다.

## 1. 왜 바꿨나 (v2.0 대본 진단)

| 증상 | 원인 | v2.1 처방 |
|---|---|---|
| "~했습니다. ~합니다. ~입니다." 반복 | 문체 규칙이 "자연스러운 존댓말"뿐, 종결어미 규칙 없음 | 내레이션 문체 모드 + "같은 종결어미 3연속 금지" |
| 대사가 거의 없음 | "성경에 없는 대사 금지" 규칙이 본문 대사까지 위축시킴 | **본문 대사는 적극 사용**(현대어 1~2문장), 없는 대사만 금지 + 1단계 대사 뱅크 |
| 장면보다 해설이 먼저 | 챕터 = 요약 단위로 설계됨 | 챕터 = 장면 단위(장소·빛·소리 → 목표·장애물·전환) |
| 매 챕터 "왜 ~했을까요?"로 끝남 | 훅 규칙이 질문 위주 | 수사 의문문 에피소드 3회 이하, 나머지는 이미지·행동·대사 훅 |
| 중간에 "그보다 앞서"로 되감기 | 시간 구조 규칙 없음 | 1장 콜드 오픈 → 2장에서만 1회 되감기 → 이후 시간순, 콜드 오픈은 후반 회수 |
| Claude 초안이 좋아도 최종본이 밋밋 | 3단계 Codex가 전체를 다시 쓰며 톤을 평탄화 | 3단계 **VOICE LOCK**(사실 오류 문장만 최소 수정) + **Claude 시네마틱 최종 보정 자동 실행** |

## 2. 내레이션 문체 모드 (UI에서 선택)

| 모드 | 방식 | 추천 |
|---|---|---|
| 시네마틱 하이브리드 (기본) | 장면은 현재형 '~다'체, 시청자에게 말 걸 때만 존댓말. 문단 단위로만 전환 | 영화 느낌 최우선 |
| 존댓말 드라마 | 전부 존댓말이지만 '~습니다' 계열 50% 이하, '~죠/~거든요/체언 종결/대사' 혼합 | 따뜻한 톤, 가족 시청 |
| 정통 소설 내레이션 | 전부 '~다'체, 엔딩 안내만 존댓말 | 오디오북 느낌 |

## 3. 작법 바이블 11개 규칙 (프롬프트 `CINEMA` 상수)

1. 장면으로 생각한다: 첫 3문장 안에 장소·시간·빛·소리 중 2개 이상, 해설은 장면 뒤에 1~2문장만.
2. 카메라처럼 배치: 와이드 → 미디엄 → 클로즈업 → 인서트. 클라이맥스 직전 문장은 짧게, 여운은 길게.
3. 종결어미·리듬: 같은 종결어미 3연속 금지, 한 문장 문단은 챕터당 2개 이하, 체언 종결은 챕터당 1~3회.
4. 대사: 챕터당 1개 이상, 전체 6개 이상(본문 근거만). 앞뒤에 침묵·행동 비트.
5. 감정은 몸으로: "두려웠습니다" 단독 금지 → 손·시선·호흡·소리.
6. 긴장 장치: 극적 아이러니, 모티프 소품 셋업·회수(창, 수금, 화살, 찢어진 겉옷), 시한폭탄("아침이 오면"), 대비.
7. 소리를 쓴다: 수금 줄, 창이 벽에 박히는 소리, 발소리, 정적. 의성어는 전체 2~4회.
8. 숨 쉬는 순간: 본문 범위 안의 따뜻함·재치 1~2회.
9. 챕터 제목은 짧은 명사형, 마지막 문장은 다음 장면으로 끌어당기는 훅. 수사 의문문 전체 3회 이하.
10. 금지: 사실 나열, 반복 질문 엔딩, "그날부터 ~하기 시작했습니다" 남발, "여러분" 3회 이상, 상투어(놀랍게도/충격적인/바로 그때였습니다 등), 설교체.
11. 출력 전 자체 점검(종결어미, 대사 수, 감각 디테일, 질문 수, 유보 문구 수, 콜드 오픈 회수).

## 4. 사실 정확성과 연출의 경계

| 허용 (연출) | 금지 (사실 왜곡) |
|---|---|
| 등잔불, 바람, 먼지, 소리, 옷감 질감, 카메라 위치 | 사건·순서·인물 관계·결과 변경 |
| 본문 대사를 현대 한국어로 짧게 풀어 직접 인용 | 본문에 없는 대사 창작 |
| 행동으로 내면 암시 | 기록되지 않은 동기 확정 |
| 본문이 직접 말한 감정 + 행동 디테일 | 번역 성경 장문 복제, 교단 해석 단정 |
| 유보 문구 전체 2회 / 추측 어미 3회 이하 | 매 문단 "본문은 ~라고 기록합니다" |

| 단계 | 변경 |
|---|---|
| 1단계 Codex 근거팩 | 콜드 오픈 후보, **대사 뱅크 8~12개(장·절)**, 극적 아이러니, 모티프 소품, 감각 팔레트, 관계의 비극, `===BEAT SHEET===` 추가 |

## 6. Before / After (사무엘상 18~20장, 1장 콜드 오픈)

**Before (v2.0)**
> 다윗이 수금을 무릎에 올리고 낮은 음을 고릅니다. 사울은 왕좌에 앉아 있습니다. 손은 곁에 세워 둔 창대에 머뭅니다. 음악이 끝나기 전에 창이 날아갑니다. 다윗은 몸을 피합니다. 창은 벽에 박혀 흔들립니다.

**After (v2.1, 시네마틱 하이브리드)**
> 밤. 궁정의 등잔불이 낮게 흔들린다. 소년의 손가락이 수금 줄 위를 천천히 건너간다. 왕좌의 사울은 눈을 감고 있다. 그런데 그 손은, 곁에 쥔 창대를 놓지 않는다.
> 가락이 가장 낮아지는 순간. 왕의 손이 움직인다.
> 쉭.
> 둔탁한 소리. 창끝이 벽에 박혀 부르르 떤다. 수금 소리는 끊겼고, 소년은 이미 어둠 속으로 사라지고 없다.
> 창을 던진 사람은 이스라엘의 왕입니다. 그리고 창을 피한 사람은, 한때 그 왕이 누구보다 아끼던 소년이었죠.
