# 성경 한 장면 스튜디오 v2.0 제작 기준

## 사실성 분류

| 등급 | 의미 | 대본 처리 |
|---|---|---|
| A | 성경 본문에 직접 기록된 사실 | 관련 권·장·절을 표기하고 핵심 근거로 사용 |
| B | 역사·문화적 배경 | 본문과 분리해 설명하고 근거를 기록 |
| C | 해석 또는 합리적 추론 | 단정하지 않고 완화 표현 사용 |
| D | 불확실하거나 근거 없는 정보 | 대본과 사실성 설명에서 제외 |

본문에 없는 대사, 감정, 동기, 외모, 나이를 실제 기록처럼 확정하지 않는다. 특정 교단의 해석을 유일한 사실로 단정하지 않으며, 현대 번역 성경 문장을 장문으로 복제하지 않는다.

## 기본 영상 사양

| 항목 | 기준 |
|---|---|
| 대상 | 성경 초보 성인, 초등 고학년 이상, 가족 시청자 |
| 러닝타임 | 7~10분 |
| 대본 | 약 3,000~3,800자 |
| 구조 | 8챕터 |
| 기본 이미지 | 24장 |
| 감정 흐름 | 평범함 → 불안 → 선택 → 긴장 → 결과 → 여운 |

엔딩은 `이야기의 실제 마지막 장면 → 핵심 교훈 또는 감동 포인트 1개 → 시청자 연결 질문` 순으로 구성한다. 성공학식 결론, 영웅화, 급작스러운 설교체를 사용하지 않는다.

## Visual Bible 최소 요건

Global Visual Bible, Character Master Anchor, Character State by Age, Location Bible, Costume Bible, Prop Bible을 분리하여 유지한다. 이미지는 역사적으로 개연성 있는 고대 근동 세계관을 따르며, 중세 유럽 판금갑옷·바이킹·현대 물품·현대 글자·로고·판타지 거대화를 제외한다.

24 Story Beat는 establishing wide 4장, medium narrative 6장, emotional close-up 5장, over-the-shoulder 3장, insert/detail 3장, atmosphere/transition 3장을 기준으로 다양하게 배정한다. 동일 shot type은 3회 연속 사용하지 않으며, 우하단 12%×12% 워터마크 안전 영역에 핵심 얼굴·손·소품·행동을 두지 않는다.

## 최종 품질 게이트

| 게이트 | 확인 항목 |
|---|---|
| Bible Gate | 본문 근거, 추론 사실화 방지, 영화 설정 혼입 방지 |
| Story Gate | 20초 도입 훅, 갈등, 8챕터 연결, 설명문 과다 방지 |
| Emotion Gate | 감정 흐름, 과장 없는 교훈, 여운 문장 |
| Visual Gate | 인물·의상·장소·소품 일관성, 시대성, shot 다양성 |

하나라도 불합격이면 전체를 재생성하지 않고 해당 섹션만 수정한다.
